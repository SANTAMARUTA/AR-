使い方
1. HTTPSの公開URLをスマートフォンのSafari / Chromeで開きます。
2. 「カメラでお祝いを見る」を押し、カメラを許可します。
3. 印刷物または別の画面に表示したバースデー画像全体を映します。
4. 画像を認識すると無音で動画を再生します。「音をON」で音声を出せます。
5. 画像を見失うと停止し、再認識すると続きから再生します。
6. 「最初から」で冒頭へ戻ります。動画は繰り返し再生します。
7. 「終了」でカメラを停止し、開始画面へ戻ります。

調整
動画の横幅はHTML内の a-video の width="1" で、ターゲット幅と同じです。
拡大する場合は width を変更し、updateAspect() 内の高さにも同じ倍率を掛けます。
ターゲットの登録番号は0です。今回のmindファイルは登録1件です。
登録寸法4123×2978は添付画像と一致しますが、画像内容が一致するかは実機認識で確認が必要です。

検証範囲
JavaScript構文・参照ファイル・模擬イベントでの再生状態遷移を確認。
スマートフォンの実カメラによる認識、映像の位置、音声許可は未確認です。
ダブルクリックで開くfile://ではARを使用できません。
外部のA-FrameとMindAR CDNの読み込みにインターネット接続が必要です。
